A clean, modern redesign of the Discord community manager portfolio.

## Changes in this version
- Removed personal hardware and gaming details
- Fixed all broken characters / encoding issues
- Replaced emoji icons with clean SVG icons

## How to use
1. Download and unzip
2. Open index.html in a browser to preview
3. Upload the files to a GitHub repo and enable GitHub Pages
